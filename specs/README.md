# Specifications

This directory contains **authoritative specifications** for each milestone
in Project VOX Personalis.

All code in this repository is expected to conform to the behavior, inputs,
outputs, and non-goals defined here.

Specs are written before implementation and may evolve over time, but changes
must be explicit and documented.
